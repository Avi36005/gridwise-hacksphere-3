    How validation works

    1. Tune on the first 3,200 hours only, with four past-to-future folds: no future hour is ever used to predict an earlier one.
    2. Choose the algorithm by mean fold error, then score the finalists once on the locked last 800 hours.
    3. Train the winner in QuickML on all 4,000 hours; QuickML's own 5-fold check on date blocks confirms the ranking.
    4. The 1,000-row sample has no labels, so its accuracy cannot be measured here.

    Published on Zoho QuickML

    Checking the server configuration…

    The server builds the 14 model features (weather, hour, weekday, seasonal cycles, heating and cooling degrees) and calls the endpoint with credentials Catalyst injects into AppSail, so no key reaches the browser or predict.py.

    QuickML's default single random 80/20 split favours AutoML (8.47 vs 8.94 kW) because a random hour's neighbours sit in training; blocked validation reflects forecasting later dates, as the hidden test does.
