# Gridwise design system

User direction: strict black and white, white background, rich readable typography, detailed 3D and restrained animation. This overrides the UI/UX skill search suggestion of a blue accent.

- Background: #fff. Primary text/actions: #111. Secondary text: #595959. Borders: #e2e2e2.
- Type: locally bundled Geist, 400–650. Main heading 32–40px, section headings 19px, body copy 15–16px, data labels 12–14px.
- Charts: black demand line, distinctly dashed thresholds, labeled values and accessible data table.
- 3D: white building and plinth, graphite glazing and solar panels, neutral shadows, visible flow routes. Drag and keyboard-accessible button rotation, pause/resume, reset.
- Motion: 200ms control feedback, 280ms chart transition, 300ms view entrance; reduced motion disables automatic motion.
- Mobile: one-column scene and insight panel, two-column metrics, collapsible navigation, contained table scrolling.

Reviewed with ui-ux-pro-max skill: high contrast, focus indicators, animation restraint, local fonts, consistent icons.
